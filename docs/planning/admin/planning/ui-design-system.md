# UI design system — Admin app

**Status:** Stub — stack locked in PRD/prompt.

## Stack

- Next.js 15 App Router, Tailwind CSS, shadcn/ui, Radix, Lucide, Sonner
- Tables: TanStack Table v8 + DataTable pattern
- Charts: Tremor or Recharts
- Maps: Leaflet + react-leaflet (Mapbox optional)

## Layout

- Dashboard shell: collapsible sidebar, topbar (user, role, logout), breadcrumbs, consistent page container.

## Theming

- Professional internal-tool aesthetic; light mode default unless product specifies dark.
