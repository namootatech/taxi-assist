# Trip Website — UI design system

## Principles

- **Clear hierarchy:** one primary CTA per viewport section.
- **Mobile-first:** most traffic from social/share on phone.
- **Brand:** align with Trip/Taxi Assist voice in `docs/system/market/` when those files cover corporate site copy.

## Structure

- Sticky header with logo + primary nav + “Get the app” CTA.
- Footer: legal, social, links to rider/driver/partner surfaces.

## Components

- Hero with headline, subcopy, dual app badges.
- “How it works” stepped layout.
- Partner strip logo wall (optional phase 2).
- Form card with clear privacy note under submit.

## Visual guidance

- High contrast, large tap targets; avoid decorative motion that hurts Core Web Vitals.
